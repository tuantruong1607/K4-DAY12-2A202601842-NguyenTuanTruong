Fail-fast có lợi gì?

Nếu để mặc định agent_api_key = "changeme", app khởi động thành công nhưng chạy sai âm thầm. Fail-fast biến lỗi cấu hình thành lỗi nhìn thấy ngay.

Lệnh: pytest tests/test_cp1.py -v

CP2DOCKER: MULTI-STAGE & NON-ROOT45 phút
Dockerfile / production runtime
# Stage 1: build dependencies
FROM python:3.11-slim AS builder
WORKDIR /build
COPY requirements.txt .
RUN pip install --no-cache-dir --prefix=/install -r requirements.txt

# Stage 2: runtime
FROM python:3.11-slim
WORKDIR /app
COPY --from=builder /install /usr/local
COPY app/ app/
COPY utils/ utils/
RUN adduser --disabled-password --no-create-home appuser
USER appuser
EXPOSE 8000
HEALTHCHECK --interval=30s --timeout=5s --retries=3 \
  CMD python -c "import urllib.request; urllib.request.urlopen('http://127.0.0.1:8000/health', timeout=3)"
CMD ["sh", "-c", "exec uvicorn app.main:app --host 0.0.0.0 --port ${PORT:-8000}"]
Thời gian CP2
45:00

Tại sao multi-stage?

Stage build có thể nặng; stage runtime chỉ copy dependency cần thiết → image production dưới 500MB, stretch goal dưới 200MB.

Bảo mật: non-root user. Lệnh: pytest tests/test_cp2.py -v

CP3API SECURITY & LIMITS45 phút

01 / API Key Auth

Mọi API nghiệp vụ cần X-API-Key khớp AGENT_API_KEY.

02 / Rate Limit

Redis Sorted Set đếm request 60 giây gần nhất. Vượt ngưỡng → 429.

03 / Cost Guard

Ngân sách mô phỏng theo tháng. Vượt budget → 402, không gọi LLM trả phí.

Prune → Count → Check → Record UUID → Expire

Hai lớp bảo vệ khác nhau

Rate limit bảo vệ hạ tầng khỏi request quá nhanh. Cost guard bảo vệ ngân sách khỏi request quá đắt.
